Help

Pages

Each page is one Brave profile. Swipe sideways or tap the names along the top. The + at the end of the names adds a page. Menu › Pages renames or deletes them; drag the ⠿ handle up or down to change their order.

Bring in your Brave bookmarks

On the computer, open Brave in the profile you want, then Menu › Bookmarks › Bookmark manager › the ⋮ button › Export bookmarks. Here, choose Menu › Import Brave bookmarks and pick that file. Repeat for each profile. Brave folders become the groups on the page, and long page titles are shortened (Menu › Tidy names on this page does the same for pages already imported; any name can be changed in Arrange). Brave on Android can't export, so do this on the computer and move everything to the tablet with a backup file.

Arrange

Tap Arrange. Drag an icon to move it, including into another group. Tap an icon to change its name, address, icon, tile colour, page or group. Tap × to remove it (Undo appears for a few seconds). Tap a group's name to rename or delete it. Tap Done when finished.

Icons

In Arrange, tap an icon, then Find icon. It shows the pictures the website offers (and one from DuckDuckGo); tap the one you like. Menu › Find icons for this page does every bookmark on the page at once. You can also use your own picture (or copy a screenshot of a logo and press Ctrl+V while editing; any shape is fitted into the square), or choose Colour tile to show the name inside a coloured square. The colour wheel at the end of the colours lets you match a site's own colour. Finding icons asks each website (or DuckDuckGo) for its picture, so they learn the site's address and nothing else. Pictures you choose yourself stay on this device.

Size

The slider sets icon size for the page you're on. Fit picks the largest size that keeps the whole page on screen.

Backups and other devices

Bookmarks are kept in this browser on this device only. Save a backup file to your cloud drive, then use Restore from backup on the other device.

Opening links

Links open in the browser this app runs in. It can't choose which Brave profile opens them.
